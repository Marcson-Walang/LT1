# LT1 Part 2

## This project helps in calculating the area, circumference, square root, and the area rounded up and down of the square garden.

## To use it, you simply need to open the file and input the radius of the square garden and it will tell you the area, circumference, square root of the area, and the area rounded up or down.

## You only need to simply input the radius of the circle with no m or km

## Example: You enter 5 as the radius, it tells you the Area, Circumference, square root and the area rounded up and down is; 78.54 square meters, 157.08 square meters, 8.86, and 78 and 79 square meters.
